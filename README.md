# Kairo

Kairo is a local-first personal command center built around Kaizen: continuous improvement through small, consistent actions.

It is not a task manager. Kairo helps its user align in the morning, track commitments during the day, reflect in the evening, and correct course each week.

## Development

```bash
pnpm install
pnpm dev
```

Run `pnpm check` before opening a pull request. Direct changes to `main` are prohibited after this bootstrap commit; every feature must use its own branch and be merged by the repository administrator.

## Product laws

1. Local first; AI is optional and explicit.
2. Daily first; every feature supports alignment, tracking, reflection, or correction.
3. Calm by design; no notification spam, gamification, or noisy dashboards.
4. Reflection over output.
5. Square, editorial surfaces with circles used only for meaningful status and identity marks.
