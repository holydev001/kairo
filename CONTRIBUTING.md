# Contributing

Never commit directly to `main`. Create a focused conventional branch using `feat/`, `fix/`, `chore/`, `docs/`, `test/`, `ci/`, or `refactor/`, then open a pull request for the repository administrator to merge. Do not use tool- or author-prefixed branch names such as `codex/`.

Each pull request must pass type checking, ESLint, Prettier, and the build. Keep changes focused and describe how they help the user align, track, reflect, or correct course.
