# Kairo MVP Product Requirements

## Promise

Kairo helps its user stay aligned with the person they are trying to become.

## Daily loop

- Morning: set an intention, three priorities, and personal commitments.
- Day: update the checklist, workout, reading, faith, and project progress.
- Evening: record wins, shortcomings, lessons, tomorrow's focus, and a daily score.
- Weekly: review patterns and correct course, with an optional user-triggered AI summary.

## v0.1

- Electron application shell and design system
- Command Center
- One daily journal entry per date
- Daily checklist desktop panel
- Local SQLite persistence

## Later MVP increments

- Reading, faith, workout, and project sections
- History calendar and weekly review
- Explicit selected-context OpenAI analysis
- Backup and export

## Non-goals

No accounts, cloud sync, social features, achievements, mobile app, collaboration, or automatic AI uploads.

## Design direction

Kairo feels like a private modern study: dark, warm, quiet, mature, and editorial. Instrument Serif carries reflective headings; Geist carries the interface. Gold marks purpose, not decoration. Layout is created by rhythm, typography, and fine rules rather than rounded cards. Small circles are reserved for completion, status, and the Kairo mark.
